# Compliance Audit Skill

A reusable evidence-driven audit skill for ISO management-system standards and PCI DSS.

Start with `SKILL.md`.

Included framework profiles:
- ISO/IEC 27001:2022 + Amd 1:2024
- ISO/IEC 27002:2022
- ISO/IEC 27701:2025
- ISO 22301:2019 + Amd 1:2024
- ISO/IEC 42001:2023
- ISO/IEC 20000-1:2018
- ISO 31000:2018
- ISO 9001:2026
- PCI DSS v4.0.1

The skill is intentionally evidence-first and read-only by default. It does not reproduce full proprietary ISO standard text and does not claim certification/compliance without sufficient scope and authorized evidence.
