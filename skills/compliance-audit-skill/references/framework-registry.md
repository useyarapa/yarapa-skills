# Framework Registry

Always verify publication status before a new audit. This registry is a starting baseline, not a substitute for a live version check.

| Framework | Baseline for this skill | Role | Notes |
|---|---|---|---|
| ISO/IEC 27001 | ISO/IEC 27001:2022 + Amd 1:2024 | Certifiable ISMS requirements | Main security management-system audit profile. |
| ISO/IEC 27002 | ISO/IEC 27002:2022 | Guidance | Control guidance; not independently certifiable. |
| ISO/IEC 27701 | ISO/IEC 27701:2025 | PIMS requirements + guidance | 2019 edition is withdrawn; 2025 is current baseline. |
| ISO 22301 | ISO 22301:2019 + Amd 1:2024 | Certifiable BCMS requirements | A replacement revision may be under development; use current published edition until replaced. |
| ISO/IEC 42001 | ISO/IEC 42001:2023 | Certifiable AI management-system requirements | For organizations developing/providing/using AI systems. |
| ISO/IEC 20000-1 | ISO/IEC 20000-1:2018 | Certifiable service-management requirements | Confirmed current by ISO at skill creation. |

## Version-check rule

Before assessment:

1. Check the official page.
2. Record current published edition and amendments.
3. Record whether the prior edition is withdrawn or in transition.
4. Do not use drafts/CD/DIS/FDIS as normative baseline unless the user explicitly asks for a draft-gap review.
5. If a scheme owner publishes transition rules, record them separately from the normative requirements.
